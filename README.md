# E-commerce Sales Dashboard | Power BI

## Project Overview
This project analyzes e-commerce sales data using Microsoft Power BI. The dashboard helps users understand sales performance, business trends, and key performance indicators (KPIs).

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Data Cleaning and Data Visualization
- Business Intelligence

## Project Files
- **Ecommerce_Sales_Dashboard.pbix** – Power BI dashboard file.
- **Ecommerce_Sales_Data.xlsx** – Source dataset used for analysis.
- **dashboard-preview.png** – Dashboard screenshot.

## Key Features
- Interactive sales dashboard
- KPI-based performance monitoring
- Visual analysis of sales data
- Business insights through charts and graphs

## How to Use
1. Download the `.pbix` file.
2. Open it using Power BI Desktop.
3. If prompted, update the source Excel file path.
4. Refresh the data if required.
